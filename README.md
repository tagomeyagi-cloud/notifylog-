# 通知履歴ログ

消してしまった通知を、後から見返せるAndroidアプリです。

> 🤖 このアプリは、AIの **Claude**(Anthropic)に作ってもらいました。
> 企画・コード・ビルドまでをClaudeとの会話で進め、私は使う側として動作確認と公開を担当しています。

スワイプで消した通知や、通知パネルから流れてしまった通知を、アプリの中でいつでも読み返せます。

## 何ができるか

| 機能 | 内容 |
| --- | --- |
| 履歴の一覧 | 届いた通知を新しい順に表示。「今日」「昨日」などの日付の見出し付き |
| 検索 | タイトル、本文、アプリ名をまとめて検索 |
| アプリ別の絞り込み | 画面上の「すべて ▾」から、アプリを選んで表示。件数も出ます |
| 全文表示 | タップすると全文を表示。文字の選択やコピーもできます |
| 個別の削除 | 長押しで1件削除 |
| 記録の一時停止 | メニューから、一時的に記録を止められます |
| 記録しないアプリ | 通知の詳細の「その他」から、アプリ単位で除外できます。戻すのはメニューの「除外アプリ」 |
| 保存期間 | 7日 / 30日 / 90日 / 無期限から選択(初期設定は30日) |
| 全て削除 | 記録をまとめて消去 |
| ダークモード | 端末の設定に合わせて切り替わります |

## プライバシーについて

通知には、メッセージ本文など、他人に見られたくない内容が含まれます。このアプリは次のように作っています。

- 記録は**端末内のデータベースにだけ**保存されます。
- **インターネット通信の権限を持っていません。** 仕組みの上で、外部へ送信できません。
- バックアップ(Googleのクラウドなど)にも**含まれません**。
- 「全て削除」、またはアプリのアンインストールで、記録はすべて消えます。
- 広告、解析ツール、アカウント登録はありません。

使っている権限は次の2つです。

| 権限 | 用途 |
| --- | --- |
| 通知へのアクセス(通知リスナー) | 届いた通知を読み取って記録するため。本アプリの中心機能です |
| すべてのアプリの一覧の取得 | 通知を出したアプリの名前(「LINE」など)を表示するため |

## 動作環境

Android 5.0(API 21)以上

## インストール方法

1. このページの「Releases」から、`notifylog.apk` をダウンロードします。
2. ダウンロードしたファイルを開き、「提供元不明のアプリ」のインストールを許可して、インストールします。
3. アプリを開き、上部の「許可する」→「設定を開く」を押します。
4. 一覧から「通知履歴ログ」を探して、オンにします。

オンにした後に届いた通知から記録されます。

### 通知アクセスがオンにできない場合(Android 13以降)

APKを直接インストールしたアプリは、通知へのアクセスが「制限付き設定」でブロックされます。「アプリはアクセスを拒否されました」と表示されたら、次の手順で解除してください。

1. 設定 →「アプリ」→「通知履歴ログ」を開きます(見つからなければ「アプリをすべて表示」)。
2. 右上の︙ →「制限付き設定を許可」を選び、画面の指示に従います。
3. もう一度、通知アクセスの画面で「通知履歴ログ」をオンにします。

︙が表示されないときは、先に通知アクセスの画面でオンにしようとしてから、アプリ情報を開き直してください。

## 記録されるもの・されないもの

**記録されます**
- 通常の通知のタイトルと本文(長い本文や、複数行の通知も含む)
- 通知を出したアプリ名と、届いた時刻

**記録されません**
- 音楽の再生中、ダウンロード中など、常駐する通知
- 複数の通知をまとめる、グループの親の通知
- タイトルも本文も無い通知
- 通知アクセスをオンにする前に届いた通知
- 画像、アイコン、通知のボタンの内容
- このアプリ自身の通知

**その他の挙動**
- 同じ通知が、10秒以内に同じ内容で更新されたときは、1件にまとめます。
- 通知パネルから通知を消しても、アプリ内の記録は消えません。
- 記録は最大2万件までで、古いものから自動で消えます。画面には新しい1000件まで表示します。

## よくある質問

**記録されません。**
通知アクセスがオンか、「記録を一時停止」になっていないか、そのアプリが「除外アプリ」に入っていないかを確認してください。画面の上に案内バーが出ている場合は、その指示に従ってください。

**しばらくすると記録が止まります。**
端末のバッテリー節約機能が、アプリを止めている可能性があります。設定の「アプリ」→「通知履歴ログ」→「バッテリー」で、制限なしにしてみてください。

**アップデートするには?**
新しい版のAPKを、そのまま上書きインストールしてください。記録は残ります(署名が同じ版に限ります)。

**Google Playにはありますか?**
ありません。個人で使うために作ったアプリなので、Releasesで配布しています。

## 仕組み(開発者向け)

- Java 製。外部ライブラリは使っていません。
- `NotificationListenerService` で通知を受け取り、SQLite に保存します。
- 画面は標準のウィジェットだけで組み、アプリのサイズを小さく(約50KB)しています。
- Gradle は使わず、Android SDK の `aapt` / `dx` / `apksigner` を使う `build.sh` でビルドします。
